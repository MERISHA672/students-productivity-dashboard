# 📚 StudyFlow — Student Productivity Dashboard

StudyFlow is a responsive student productivity dashboard built with HTML, CSS, and JavaScript.

## ✨ Features

- Add and manage study tasks
- Mark tasks as completed
- Delete tasks
- Track total, completed, and remaining tasks
- Automatic progress percentage
- Task priority levels
- Dark mode
- LocalStorage data persistence
- Responsive design for mobile and desktop

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- LocalStorage
- Responsive Web Design

## 🎯 Purpose

This project demonstrates practical frontend development skills including DOM manipulation, JavaScript functions, event handling, browser storage, responsive layouts, and UI design.
